# ШАБАКЕН CLUB 🐶

Шуточный игровой сайт: собачьи слоты, лутбоксы с коллекцией и европейская рулетка.

## Играть

[Открыть сайт](https://krzyslek.github.io/shabaken-club/)

Все шабакены и предметы виртуальные. Настоящих платежей, денежных призов и вывода средств нет. Баланс и коллекция сохраняются в localStorage текущего браузера.

## Файлы

- `index.html` — страница приложения.
- `style.css` — оформление и адаптивная верстка.
- `app.js` — игровая логика, вероятности и локальное сохранение.
- `dogs.png` — авторский атлас иллюстраций.

Сайт не требует сборки и публикуется GitHub Pages из корня ветки `main`. Изменения, отправленные в эту ветку, обновляют сайт автоматически.

Для локального запуска используйте любой статический HTTP-сервер. Фигурки авторские; сайт не связан с Funko.

## Фотографии

Мордочки животных используют реальные фото из `assets/`. Авторство и лицензии перечислены в [credits.html](assets/credits.html). Бульдог — вырезка из предоставленной пользователем фотографии; обработка встроенным ImageGen, [запрос](assets/bulldog-prompt.txt). Виниловые фигурки и сундук продолжают использовать игровой атлас `dogs.png`.
